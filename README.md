# Лабораторные работы №4–5 — Unit-тестирование и CI/CD

## Описание проекта

Проект разработан на Python для изучения модульного тестирования с использованием стандартной библиотеки `unittest`, а также автоматизации тестирования с помощью GitHub Actions.

Реализованы функции вычисления площади и периметра трёх геометрических фигур:

- Прямоугольник
- Треугольник
- Круг

Для проверки корректности работы программы подготовлено 30 автоматизированных тестов.

В рамках лабораторной работы №5 настроен автоматический запуск тестов после каждого `push` в репозиторий на двух операционных системах: Ubuntu и Windows.

## Лабораторная работа №4 — Unit-тестирование

### Функциональность

| Модуль | Функции | Описание |
|---|---|---|
| `rectangle.py` | `area`, `perimeter` | Площадь и периметр прямоугольника |
| `triangle.py` | `area`, `perimeter` | Площадь по формуле Герона и периметр |
| `circle.py` | `area`, `perimeter` | Площадь круга и длина окружности |

При передаче отрицательных размеров функции генерируют `ValueError`. Для треугольника также проверяется выполнение неравенства треугольника.

### Запуск тестирования

Перейти в корневую папку проекта и выполнить:

```bash
python3 -m unittest discover -v
```

Для запуска отдельных модулей:

```bash
python3 -m unittest -v test_rectangle
python3 -m unittest -v test_triangle
python3 -m unittest -v test_circle
```

## Лабораторная работа №5 — CI/CD

### Описание

Для автоматизации модульного тестирования используется GitHub Actions.

В проект добавлен workflow-файл `.github/workflows/main.yml`, который запускает unit-тесты после каждого `push` в репозиторий.

Тестирование выполняется на двух встроенных GitHub-hosted runner:

- `ubuntu-latest`
- `windows-latest`

### Конфигурация workflow

```yaml
name: Unit Tests

on:
  push:

jobs:
  test:
    name: Tests on ${{ matrix.os }}
    runs-on: ${{ matrix.os }}

    strategy:
      matrix:
        os: [ubuntu-latest, windows-latest]

    steps:
      - name: Checkout repository
        uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.12'

      - name: Run unit tests
        run: python -m unittest discover -v
```

### Принцип работы

1. После выполнения `git push` автоматически запускается workflow.
2. GitHub Actions создаёт два независимых задания для Ubuntu и Windows.
3. На каждом runner устанавливается Python 3.12.
4. Выполняется команда `python -m unittest discover -v`.
5. Результаты тестирования сохраняются в истории GitHub Actions.

На каждой операционной системе запускаются 30 unit-тестов.

### Результаты CI/CD

Результаты выполнения workflow доступны во вкладке **Actions** репозитория GitHub.

Успешное выполнение подтверждается зелёными индикаторами для заданий Ubuntu и Windows.

В рамках лабораторной работы №5 настроена автоматизация тестирования с помощью GitHub Actions. После каждого `push` тесты запускаются на двух операционных системах — Ubuntu и Windows.
